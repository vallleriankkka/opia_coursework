# Курсовой проект
## Реализация программы контроля облачной инфраструктуры
### Этап 1
#### 1. Назначение программы. 
Программа на языке C предназначена для анализа работы облачной инфраструктуры по последовательности телеметрических измерений. Программа получает значения показателей инфраструктурных компонентов за последовательные интервалы времени, формирует временные ряды, вычисляет производные показатели динамики, выявляет инциденты по заданному правилу.
#### 2. Описание индивидуального варианта. 
Вариант №13\
Компоненты: QRY, RPC, NIC\
Порядок записи: А — время — компонент — значение. Разделитель: точка с запятой.\
Тип последовательности (2): Порядок компонентов произвольный; на каждом отсчёте есть все три компонента.\
Телеметрия за пять отсчётов — одна строка:\
4;NIC;33.4;1;QRY;41.9;4;QRY;48.8;4;RPC;51.4;3;NIC;34.1;5;QRY;49.3;3;RPC;53.4;2;RPC;55.4;2;NIC;29.5;1;RPC;57.4;2;QRY;47.8;3;QRY;48.3;5;RPC;54.8;5;NIC;32.6;1;NIC;30.2\
Производный показатель Q: Изменение на единицу периода.\
Формула:
```
Q[i] = (X[i] − X[i−k]) / k; k = 1; L = 1.0; D = 10
```
Правило состояния компонента — Серия отклонений: Если |Q| > L два измерения подряд, состояние «ПРЕДУПРЕЖДЕНИЕ», иначе «НОРМА».\
Правило инцидента — Противоположные тенденции: Инцидент возникает, если один компонент имеет состояние «РОСТ», а другой одновременно — СНИЖЕНИЕ».\
Структура Incident:\
typedef struct { int time; int type; } Incident;\
Поля: номер отсчёта, тип инцидента.\
Проверь: вручную рассчитай Q для доступных пар, определи состояния компонентов и запиши булево выражение инцидента.\
